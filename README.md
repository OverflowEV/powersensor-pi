# PowerSensor Pi (OverflowEV)

Flashable Raspberry Pi Zero W image that discovers PowerSensor plugs on your LAN and pushes home watts to OverflowEV Home push.

**Download:** see [Releases](https://github.com/OverflowEV/powersensor-pi/releases).

**Guide:** https://overflowev.com/guides/home/powersensor-pi

Setup WiFi: `PowerSensor-xxxxx` / password `powersensor` → http://10.42.0.1
